# 🎮 Rock Paper Scissors Game - C++


The player competes against the computer through multiple rounds with colored results and final score tracking.

## ✨ Features

* 🎲 Random computer choices
* 🕹️ Multiple game rounds
* 🏆 Winner tracking
* 🎨 Colored console feedback
* 🔁 Play again option
* 💡 Built for practicing problem-solving and C++ fundamentals

## 🛠️ Concepts Used

* Enums
* Functions
* Loops & conditions
* Random number generation
* Console applications in C++

## 🚀 Technologies

* C++
* Windows Console
